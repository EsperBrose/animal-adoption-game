# Animal Adoption Game — Plan

A cute 2D, top-down browser game: visit the magic pond, turn into any animal you want,
then win over a family in town so they adopt you. Hosted on GitHub Pages.

## Phase 1 — Setup
- [x] Create GitHub repo with `PLAN.md` and README
- [x] Starter game page (`index.html`) with a canvas and the magic pond
- [ ] GitHub Pages turned on so the game has a playable link

## Phase 2 — Become an animal
- [ ] Animal picker (dog, cat, bunny, fox, horse, dragon…) plus a "type any animal" box
- [ ] Choose your animal's name and color
- [ ] Walk your animal around with arrow keys / WASD

## Phase 3 — Get adopted
- [ ] Families walk around the town
- [ ] Do tricks, cuddle, or play to fill a family's ❤️ meter
- [ ] Full meter → they adopt you → "Adopted!" celebration

## Phase 4 — Your new home
- [ ] A house with your family: eat, sleep, play
- [ ] Go back to the pond to change into a different animal any time
- [ ] Save progress in the browser
