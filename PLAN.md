# Animal Adoption Game — Plan

A **boxy 3D** browser game (blocky animals and world, built with Three.js): visit the magic pond,
turn into any animal you want (or a human!), then win over a family in town so they adopt you.
Hosted on GitHub Pages.

## Phase 1 — Setup
- [x] Create GitHub repo with `PLAN.md` and README
- [x] Starter game page (`index.html`) with the magic pond
- [x] GitHub Pages turned on so the game has a playable link

## Phase 2 — Become an animal
- [x] Boxy 3D world: grass tiles, magic pond, trees, flowers, fence
- [x] Animal picker (dog, cat, bunny, fox, horse, dragon…) plus a "type any animal" box
- [x] Choose your animal's name and color
- [x] Walk your animal around with arrow keys / WASD or by tapping

## Phase 3 — Get adopted
- [x] More land, plus a town with houses, and families who walk around, stop and wave
- [x] Human mode: one button turns you into a human and back; choose girl / boy / other, skin, hair and clothes
- [x] A forest in the south: pine trees, mushrooms, rocks and darker grass
- [x] Real-life sizes (elephants and giraffes are huge, tiny animals stay visible), and choose to be a baby or an adult animal
- [x] Do tricks, cuddle, or play to fill a family's ❤️ meter
- [x] Full meter → they adopt you, pick you up and carry you home (big animals walk) → "Adopted!" celebration, and your family follows you

## Phase 4 — Your new home and the store
- [x] Go inside your family's house (a boxy room)
- [x] Coins: earn them by playing (making families happy, finding coins around the land)
- [x] Town store: buy furniture, toys, pet beds and hats
- [x] Decorate: place the things you bought in your house
- [x] Eat, sleep and play at home (food, sleep and fun meters; food bowl, beds, sofa, teddy and TV)
- [x] Save progress in the browser (coins, purchases, hats, adoption, furniture; "Start a new game" to reset)

## Phase 5 — Adoption center (play with friends)
- [ ] Set up Firebase, a free online service that connects players (you create the project; Claude guides you)
- [ ] Room codes: share a code like PUPPY-42 so only friends can join your world, and see each other move
- [ ] Emotes only (👋 ❤️ 🎉), no typed chat, to keep it safe
- [ ] Adoption center building: animal players wait there and human players adopt them
- [ ] Adopted friends join your family and come home with you

## Phase 6 — Islands
- [x] An airport with a boxy airplane, plus the sea all around the land
- [ ] Fly to another island (a short flight across the sea)
- [x] Sunny Island to explore: beach, palm trees, smoothie hut, runway, coins and wild monkeys, parrots, turtles, frogs and an elephant
