# 🐾 Animal Adoption Game

A cozy 2D browser game where you can turn into **any animal you want** and get **adopted** by a family.

**Play it:** https://esperbrose.github.io/animal-adoption-game/

## How it works
1. Visit the magic pond and choose your animal.
2. Explore the town and meet families.
3. Make a family happy so they adopt you!

## Development
It's plain HTML, CSS and JavaScript, so there's nothing to install. Open `index.html` in a browser,
or use the GitHub Pages link above. See [PLAN.md](PLAN.md) for the phases and milestones.
